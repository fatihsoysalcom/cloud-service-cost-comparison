# Cloud Service Cost Comparison

This Python script provides a simplified, conceptual comparison of hypothetical cloud service costs between Azure and AWS. It illustrates the basic principle of analyzing pricing models and usage to make informed decisions, a key aspect when choosing between cloud providers like those covered by AZ-900 and AWS Cloud Practitioner certifications.

## Language

`python`

## How to Run

Save the code as `cloud_cost_compare.py` and run it from your terminal using: `python cloud_cost_compare.py`
